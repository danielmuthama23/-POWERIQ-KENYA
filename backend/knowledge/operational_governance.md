# POWERIQ operational governance

POWERIQ is a decision-support prototype. It is not connected to any grid control system and exposes no tool that can issue commands to infrastructure. All outputs are advisory. Recommendations are stored with a pending status and require an authorised human approver to record a decision; every agent run, scenario and approval is written to a tamper-evident audit log. Read-only analysis and operational actions are kept separate by role.
